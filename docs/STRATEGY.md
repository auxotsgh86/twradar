# 右側加碼雷達：操作邏輯說明

> 版本：v0.3（2026-11-13，依專家審閱意見修訂）
> 用途：說明系統的上車、加碼、減碼、退場與大戶判斷邏輯，供籌碼與控盤實務專家審閱。
> 下列規則都已在系統中實作，門檻可在設定頁調整。
> 第 8 節是審閱意見的採納紀錄，第 9 節是下一步要用歷史資料驗證的項目。

---

## 0. 設計原則

1. **右側交易**：不猜底。均線還沒翻揚前，站上月線也不算右側。
2. **判斷不明時，站在大戶的角度想**：「如果我是大戶，我會怎麼做？」
   - 大戶不會在虧損時加碼攤平。
   - 大戶出貨時，需要散戶接手：股東人數增加、融資增加。
   - 大戶吸籌時，股票從多數散戶流向少數人：大戶持股比例上升、股東人數減少。
   - 大戶拉高出貨時，會留下「高檔出量的長上影線」或「高檔爆量長黑」。
3. **系統只給訊號，不下單**：最後是否進出由人決定。
4. **只用盤後公開資料**：沒有盤中即時資料，也沒有券商分點資料。

## 1. 使用的資料

| 資料 | 來源 | 頻率 |
|---|---|---|
| 收盤行情（開高低收、成交量、成交金額） | 證交所、櫃買中心 | 每日 |
| 三大法人買賣超 | 證交所、櫃買中心 | 每日 |
| 融資融券餘額 | 證交所、櫃買中心 | 每日 |
| 加權指數 | 證交所 | 每日 |
| 集保股權分散表（各持股級距的人數與股數） | 集保結算所 | 每週（從接入當週開始累積） |

## 2. 名詞與計算方式

| 名詞 | 計算方式 |
|---|---|
| **還原股價** | 除權息、減資當天，交易所的「漲跌」是相對於參考價。系統偵測到「收盤 − 漲跌 ≠ 前一日收盤」時，把之前的股價按比例還原。所有均線、前高都用還原股價計算，避免除息跳空被誤判為跌破月線。 |
| 5 日線、月線、季線 | 最近 5、20、60 個交易日的還原收盤平均 |
| 月線方向 | 今日月線與昨日月線比較：≥ 為走平或上揚 |
| 量比 | 當日成交量 ÷ 前 5 日平均成交量（不含當日） |
| 前高 | 前 20 個交易日（不含當日）的最高還原收盤價 |
| 法人連買 N 日 | 外資（或投信）連續 N 個交易日買超 |
| 法人由賣轉買 | 外資或投信連買第 1～2 天，且再前一天為賣超 |
| 買超放大 | 見 4.2 |
| 法人合計 | 外資＋投信（不含自營商） |
| 月線乖離 | （收盤 ÷ 月線 − 1）× 100% |
| 持有報酬 | 以成本價計算，扣除手續費（0.1425%）與證交稅（0.3%） |
| 市值 | 集保總股數 × 收盤價（判斷大型股用） |

## 3. 燈號總覽

| 面向 | 適用 | 燈號 |
|---|---|---|
| 進場面 | 所有觀察個股 | 上車訊號（未持有）／加碼訊號（持有中）／觀察中／不宜加碼 |
| 持有面 | 標記為「持有中」的個股 | 續抱／減碼／退場 |

顏色依台股慣例「多紅空綠」。規則由上往下判斷，先符合者為準。

## 4. 進場面：上車與加碼

### 4.1 判斷順序

1. 資料不足 → **資料不足**
2. 任一否決條件成立（4.4）→ **不宜加碼**
3. 大盤逆風（4.5）→ **觀察中**
4. 投信買、外資賣（4.6）→ **觀察中**
5. 持有中，且符合加碼條件（4.3）→ **加碼訊號**
6. 未持有，且符合上車條件（4.2）→ **上車訊號**
7. 其他 → **觀察中**，並列出「還差哪些條件」

### 4.2 上車（未持有，建底倉）

目的：抓「起漲轉折」，拿到低成本優勢。部位小，容錯率高。以下全部成立：

| 條件 | 定義 |
|---|---|
| 月線走平或上揚 | 今日月線 ≥ 昨日月線，或 5 日線 > 月線 |
| 回測月線有守 | 近 10 日最低價曾回到月線上方 2% 以內，且期間收盤沒有跌破月線超過 1.5% |
| 帶量紅 K | 收盤 > 開盤，且量比 > 1 |
| 站上 5 日線與月線 | 收盤 > 5 日線，且收盤 > 月線 |
| 法人轉買 | 外資或投信由賣轉買第 1～2 天；或符合「法人買超」（見下） |

**法人買超**（以下任一）：
- 外資或投信連買 ≥ 2 日
- 外資或投信**買超放大**，三項都要成立：
  - 前 4 日合計為淨買超
  - 當日買超 ≥ 前 4 日平均的 2 倍
  - 當日買超佔成交量 ≥ 10%，或金額 ≥ 3,000 萬元

### 4.3 加碼（持有中，放大部位）

目的：抓「脫離成本區後的趨勢加速」。以下全部成立：

| 條件 | 定義 |
|---|---|
| 底倉已獲利 | 帳面獲利 ≥ 3%。**絕不在虧損或剛平盤時加碼攤平** |
| 帶量突破前高 | 收盤 > 前高，量比 > 1，且月線走平或上揚 |
| 法人買超 | 同 4.2 |

### 4.4 否決條件（任一成立就是「不宜加碼」）

| 條件 | 定義 | 大戶角度 |
|---|---|---|
| 跌破月線 | 收盤 < 月線 ×（1 − 0.5%） | 趨勢未成立 |
| 爆量長黑 | 跌幅 ≥ 3%，且量比 ≥ 1.5 | 有人在倒貨 |
| 籌碼背離 | 收紅，但法人合計賣超，且融資增加 | 拉高讓散戶接 |
| 法人賣、融資接 | 收黑或留長上影，法人合計賣超，且融資增加 | 散戶接刀 |
| 融資追價過熱 | 法人買超，但融資增加 > 法人買超張數 | 主導權在散戶 |
| 外資買、投信賣 | 投信賣超 ≥ 外資買超的 25%，且金額 ≥ 5 日均成交金額的 3% | 投信砍倉常一波到底 |

**融資的角色**：融資不再是加碼的必要條件。主升段常見「價漲融資增」，只要融資增加 < 法人買超的 30%，視為健康（中實戶順勢或主力鎖碼）；超過法人買超才否決。

### 4.5 大盤濾網

加權指數收盤低於月線，**且**月線下彎 → 所有上車／加碼訊號降為「觀察中（大盤逆風）」。

> 上櫃股目前也用加權指數判斷，尚未接入櫃買指數。

### 4.6 投信買、外資賣

投信買、外資賣，且較小一方 ≥ 較大一方的 25%，金額也達門檻 → 列為「觀察中」，不直接否決。這種情況可能是外資被動調節、投信主動認養。

### 4.7 關鍵價

可為個股設定關鍵價。報表會顯示是否站上、量能是否確認；持有時，跌破關鍵價就停損（5.1）。

## 5. 持有面：減碼與退場

只看標記為「持有中」的個股。由上往下判斷，先符合者為準。

### 5.1 停損（退場，當日執行）

任一成立：

| 條件 | 定義 |
|---|---|
| 有效跌破下彎月線 | 收盤 < 月線 ×（1 − 1.5%），且月線下彎。**不必等法人** |
| 跌破月線＋法人賣 | 收盤 < 月線 ×（1 − 0.5%），且當日法人合計賣超 |
| 跌破關鍵價 | 有設定關鍵價時 |
| 保本線 | 買進後最高獲利曾 ≥ 10%，現在回吐到 ≤ 2%（需填成本與買進日） |
| 硬停損 | 虧損 ≥ 10%（以成本計，含費稅）。最後一道保險 |

> 右側交易的進場理由是「站上月線／突破」。理由消失時（結構破位）就該走，通常虧損只有 3～5%，不必等到 10%。

### 5.2 獲利出場（退場，當日執行）

獲利 ≥ 10%，**且**符合下列任一：
- 跌破月線（超過 0.5%）
- 籌碼轉弱 ≥ 3 項（見 5.4）

### 5.3 出貨警訊（減碼，當日執行）

任一成立，不論獲利多少：

| 條件 | 定義 |
|---|---|
| 高檔爆量長黑 | 昨收距近 20 日最高 ≤ 5%（位於高檔），跌幅 ≥ 3%，量比 ≥ 1.8，且法人合計賣超 |
| 高檔出量長上影 | 盤中漲幅 ≥ 7% 後被打下，上影線 ≥ 當日振幅的 50%（或 ≥ 實體的 1.5 倍），且量比 ≥ 1.5 |
| 爆量打開漲停 | 盤中漲幅 ≥ 9.5%，收盤未鎖，且量比 ≥ 2 |
| 乖離過大且轉弱 | 月線乖離 ≥ 15%（市值 ≥ 1,000 億的大型股為 10%），**且**收黑或留上影線 |

**不列為出貨警訊：**
- 鎖住漲停且量縮：代表惜售。
- 紅 K 強勢創高：乖離再大也不急著減碼，等第一根轉弱 K 線出現。

### 5.4 獲利保護（減碼）

前提：獲利 ≥ 10%，且籌碼轉弱 ≥ 2 項。建議先減一半。

**籌碼轉弱四項：**

| 項目 | 定義 | 頻率 |
|---|---|---|
| 大戶減碼 | 大戶持股比例較上週減少（大戶定義見 6.1） | 週 |
| 散戶增加 | 集保總股東人數週增 ≥ 1%；或融資連增 ≥ 2 日 | 週／日 |
| 融資偏高 | 融資餘額位於近 60 日區間的前 20%，且 60 日融資變化 ≥ 1,000 張（或 ≥ 股本 1%）。後者是防呆，避免融資只從 100 張變 105 張也被算成高檔 | 日 |
| 法人連賣 | 外資＋投信合計連賣 ≥ 2 日 | 日 |

### 5.5 訊號確認

- 停損、獲利出場、出貨警訊：一律**當日執行**。台股有漲跌幅限制，多等一天可能多跌一兩根停板。
- 籌碼轉弱各項本身已包含多日條件（例如連賣 2 日），不需要再加確認天數。
- 其他規則可以設定「連續 N 日成立才轉換燈號」，預設 N = 1。

### 5.6 持有成本的角色

成本只用在以下幾處：

- 加碼前提（獲利 ≥ 3%）
- 硬停損（虧損 10%）
- 保本線
- 獲利出場與獲利保護的啟動門檻（10%）

其他條件都只看市場資料。

## 6. 大戶與散戶

### 6.1 大戶：以持股市值定門檻

- **預設：持股市值 ≥ 1 億元。** 以 60 日均價換算張數，再對到集保 15 個級距中最接近的一級，所以同一套邏輯可以適用 20 元到 5,000 元的股票。舉例：
  - 股價 1,200 元：1 億元約 83 張，對到 100 張以上
  - 股價 50 元：1 億元為 2,000 張，對到 1,000 張以上（集保最高級）
- 用 60 日均價而不是當週收盤價，是為了避免股價波動讓級距每週跳動，產生假的大戶增減。
- **個股可另設張數**，也可以改成固定張數（例如千張大戶）。
- 觀察的是大戶持股比例的**週增減**。
- **已知雜訊**：最高級距包含 ETF 與外資保管帳戶。權值股的變化可能來自 ETF 申購買回。

### 6.2 散戶：看集保總股東人數

- 不糾結看哪個張數級距（高價股買 1～5 張已經是中實戶，低價股散戶在 1～50 張），直接看**總股東人數週增減率**。
- 籌碼集中（大戶吸籌）：大戶持股比例上升，且總股東人數減少。
- 籌碼發散（大戶出貨）：大戶持股比例下降，且總股東人數增加。

### 6.3 日資料的近似

集保表一週一次。一週之中，「大戶賣」以法人合計連賣近似，「散戶買」以融資連增近似。

## 7. 已知限制

1. **沒有分點資料**：「主力」那一項無法判斷，暫以法人與集保大戶代替。
2. **沒有盤中資料**：K 線型態只能用當日開高低收推估；漲停以漲幅推估，未依升降單位精算。
3. **法人買賣超含 ETF 申購買回**：權值股的數字可能混入被動資金。
4. **集保歷史要累積**：開放資料只提供最新一週，第二週起才有週增減。
5. **成本、買進日要手動輸入**：系統不連接券商帳戶。
6. **還原股價**以交易所的漲跌推算；中間缺資料的日子不調整。

## 9. 下一步：用歷史資料驗證

規則與門檻多數來自經驗。接下來用歷史資料回頭檢驗每個訊號出現後的實際走勢，再決定是否調整。驗證時要注意：

- 樣本數：觀察清單只有十幾檔，資料約一年，樣本有限。
- 避免過度擬合：保留最近一段時間不參與調整，只用來驗證。
- 倖存者偏差：觀察清單是事後挑的強勢股。
- 集保與融資的週資料、月營收等，歷史不足的部分無法回測。
